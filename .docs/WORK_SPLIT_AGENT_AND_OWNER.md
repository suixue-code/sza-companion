# 协作分工：助手能做的 / 未来能做的 / 负责人能做的

本文记录仓库内外工作的边界，便于排期与验收。与二期任务追踪配合阅读：[PHASE_2_TASKS.md](./PHASE_2_TASKS.md)。

---

## 1. 助手当前会话内能做的（仓库 + 本地）

- **读/改代码与站内文档**：路由、`hreflang`、`BaseHead`、页面文案、`.docs/` 下手册等。多语 URL 与 alternates 矩阵见 [HREFLANG_COVERAGE.md](./HREFLANG_COVERAGE.md)。
- **跑本地命令**：例如 `npm run build`、检索死链或配置一致性（在环境允许范围内）。
- **按既定约束起草文案**：着陆页首段、Playbook 增补条目、隐私/广告相关段落草稿（定稿由负责人确认）。
- **维护任务表与验收描述**：更新 `PHASE_2_TASKS.md` 等追踪文档中的状态与说明。

---

## 2. 助手在未来任务中可继续做的

- **实现已拆好的工程项**：如 T7（`src/i18n/routes.ts` 与对称页）、T8（核心页结构与首段）、T9（`ANALYTICS_AND_GSC_PLAYBOOK.md` 扩展）等见任务表。
- **基于你提供的 GSC/导出数据做归纳**：例如高展示低点击 URL 清单、建议优先改标题还是首段（数据需你导出或粘贴）。
- **在已合并的分支上迭代**：小步提交、与现有代码风格一致。

---

## 3. 只能由负责人做的（助手无法替代）

| 类别 | 说明 |
|------|------|
| **Search Console / Bing Webmaster** | 域名验证、查看效果与索引、请求编入索引、导出报表；需负责人账号。 |
| **游戏与社区事实核对** | Roblox 实机、Discord/官方渠道验码、数值与机制的最终真伪；写入 `codes.json`、`source-ledger.json` 等以负责人或流程为准。 |
| **部署与生产** | 推送托管、CI secrets、确认线上 `robots.txt`/站点地图与构建产物一致。 |
| **产品与合规拍板** | 是否接入广告、隐私与免责声明终稿、多语内容是否全文投入。 |
| **运营节奏** | 每月 GSC 复盘、核心更新窗口加频查看；助手可把清单写进文档，执行依赖负责人日历。 |
